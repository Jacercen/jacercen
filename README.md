## Projects

### ☀️ [GoodWe Dashboard](https://github.com/Jacercen/goodwe-dashboard)

I started this project to explore how data from a solar installation could be displayed in a custom dashboard.

The interface is designed to show energy production, household consumption, battery status, power flows, charts, and weather information.

I'm still working through the integration with the external monitoring service, which depends on API access and backend availability.

**Built with:** React, JavaScript, Vite and Axios.

### 🎮 [GameHub](https://github.com/Jacercen/gamehub)

A video game catalog built with React and the RAWG API.

You can search for games, sort the results, view game details and screenshots, and save favorites.

While building it, I worked with reusable components, custom Hooks, React Router, Context API and `localStorage`.

**Built with:** React, JavaScript, Vite, Axios and React Router.
